## IDE и AI
- Основное: VS Code (иногда Cursor).
- AI использую как помощника: быстро накидать код, подсказать ошибки, объяснить непонятные места.
- Цель — быстрее собрать рабочее решение.

## Какая модель под какие задачи
- Для кода/рефакторинга беру “самую умную” доступную модель.
- Для текстов/инструкций — более быструю.
- Выбираю по результату, а не по названию.

## MCP
- Почти не использую. Если подключаю — чтобы ассистент видел файлы проекта и меньше путался.

## Системные инструкции / cursorrules
Да, использую простые правила:
- не выдумывать то, чего не проверил;
- если не уверен — писать что нужно проверить;
- писать понятный код (функции, нормальные ошибки);
- всегда добавлять инструкцию запуска.
