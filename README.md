# tz-polza

В репозитории 2 скрипта:
1) `email_check.py` — проверка домена email, MX-записей и SMTP handshake.
2) `telegram_send.py` — отправка текста из `.txt` в приватный Telegram-чат через бота.

---

## Требования
- Python 3.10+
- Доступ в интернет
